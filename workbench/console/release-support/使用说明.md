# 阿拉克涅 · Mac 工作台

适用于 Apple Silicon Mac，最低 macOS 14。解压 ZIP，将「阿拉克涅」拖到「应用程序」后打开。首次启动会载入示例工程。工程、个人库和设置与应用本体分开保存。

通过「文件 → 新建工程」使用示例模型，或导入自己的模型。「渲染 → 路径追踪出图…」使用工程相机、灯光和材质生成 PNG 或 OpenEXR。「文件 → 导出…」可以烘焙八通道 4K 贴图并导出 GLB、工程与贴图 ZIP 或包含渲染的交付 ZIP。用「文件 → 打开涂装 ZIP…」恢复可编辑工程。

新工程的导入、涂装、烘焙和出图无需安装 Blender。旧 `.blend` 涂装工程可以使用「文件 → 迁移为 GLB 工程…」，这一步需要本机 Blender。迁移完成后，可以独立编辑和导出 GLB 工程。

在材质区选中蒙版，在「蒙版效果」添加磨损、噪声或其他效果，按面板显示的顺序从下到上合成。例如，用「相减」从磨损区扣除噪声，用「取大」保留两个蒙版中较亮的区域。要让手绘修正直接作用于结果，将「手绘修正」设为「在效果后」。在绘制区用 Shift 或 ⌘ 多选图层，再拖入图层组，或通过右键菜单批量移动、复制和删除。每次批量操作可以一次撤销。

如果顶栏显示「笔触未保存」，请保留当前窗口并点击「重试保存笔触」。应用先核对工程修订和已经写入的笔触，再尝试保存剩余笔触。「布局未保存」时使用面板内的「重试保存布局」；若另一窗口保存了布局，界面会让你选择保留哪一份。
